# Contributing

This is a public companion repository — it holds marketing-grade documentation, architecture overviews, and API specifications for a Thornveil system whose implementation lives in a separate proprietary repository.

## What this repo welcomes

- **Documentation fixes** — typos, broken links, factual corrections to the architecture overview
- **API spec contributions** — improvements to OpenAPI specs, additional examples
- **Translation** — non-English versions of the README

## What this repo does NOT accept

- Implementation source code — it lives in the private repository for licensing reasons
- Feature requests — track those at `jesse@thornveil.ai` or via your commercial license point of contact

Open a PR or an issue. Thornveil's engineering team reviews on a weekly cadence.
